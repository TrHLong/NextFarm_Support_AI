# NextFarm v10.3 – Simulation AI lifecycle

## Scope
Tất cả model trong `model-artifacts/simulation-v103` là **SYNTHETIC_SIMULATION_ONLY**. Không dùng để tự động điều khiển thiết bị production.

## 1. Packaging
Mỗi capability có `.joblib` và `.pkl`. Pipeline preprocessing (median imputer), feature list, target, task, run_id và scope nằm trong artifact.

## 2. Serving
FastAPI service: `services/ai-model-serving-service`.

Chạy local:
`cd services/ai-model-serving-service` rồi `NEXTFARM_MODEL_DIR=../../model-artifacts/simulation-v103/latest/models NEXTFARM_AI_MODE=shadow uvicorn app.main:app --host 0.0.0.0 --port 8080`

Docker:
`docker build -f services/ai-model-serving-service/Dockerfile -t nextfarm-ai:v10.3 .`
`docker run -p 8080:8080 -e NEXTFARM_AI_MODE=shadow nextfarm-ai:v10.3`

Các mode:
- `shadow`: tính và ghi log, response không trả prediction actionable.
- `ab10`: stable hashing mở prediction cho 10% `entity_id`.
- `simulation`: trả prediction cho toàn bộ request; chỉ dùng demo/test.

## 3. Integration
Online: POST `/predict/{model_name}` với `entity_id` và feature vector đúng schema trả từ `/models`.
Batch: `python scripts/batch_inference_v103.py --model ... --input ... --output ...`.

## 4. Shadow/A-B
Shadow là mặc định Docker. A/B 10% dùng deterministic SHA-256 bucket, cùng entity luôn ở cùng nhóm. Chỉ bật A/B khi dữ liệu thật và acceptance gate đã đạt; bản synthetic dùng để kiểm thử cơ chế.

## 5. Monitoring/retraining
Inference log JSONL lưu latency, model, entity, mode, exposed và result. `scripts/monitor_ai_v103.py` tạo summary latency/exposure.
Retrain simulation phải chỉ định `--scope simulation`; production bắt buộc chuyển qua `train_production_safe.py` và Data Readiness Gate.
